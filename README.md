# **JAVA Calculator Application**

## Project Description

This is a basic calculator application developed using JAVA as the part of the Saiket Systems JAVA Development Internship. The application allows users to perform arithmetic operations through a menu-driven interface. 

## Features

* Addition
* Subtraction
* Division
* Multiplication
* Menu-driven operation selection
* Repeat calculations until user exist
* Division-by-zero exception handling
* Invalid menu selection handling
* Non-numeric input handling 

## Technology

* Java
* Java Scanner
* Exception Handling (try-catch)
* Conditional Statements(it-else)
* Switch statement
* Methods and Loops

## How to Run

1. Open Calculator.java.
2. Click the green Run button beside the main() method.
3. Select an operation from the menu.
4. Enter the required numbers.
5. Select option 5 to exit.
